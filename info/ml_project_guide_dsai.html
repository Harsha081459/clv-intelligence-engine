Core algorithms

Feature engineering (the hard part)

This plan works for any of the top-3 projects. Adjust dataset-specific steps accordingly.

Week 1 — Data & EDA
  • Download dataset, audit schema, document every column
  • Exploratory data analysis: distributions, nulls, target rate, class imbalance ratio
  • Correlation heatmap, bivariate analysis vs target
  • Define train/val/test splits with temporal stratification if time-based
Week 2 — Feature engineering
  • Null imputation strategy per column (mean/median/mode/flag)
  • Categorical encoding: OHE for low-card, target encoding for high-card
  • WoE transformation for logistic regression scorecard
  • Feature interaction construction, polynomial terms
Week 3 — Modeling
  • Logistic Regression baseline with L1 regularization (feature selection signal)
  • Random Forest with OOB score, GridSearchCV on depth/n_estimators
  • XGBoost with Optuna hyperparameter search, early stopping
  • LightGBM for comparison, CatBoost if high-cardinality categoricals
Week 4 — Evaluation & explainability
  • Full evaluation suite: ROC, PR-AUC, KS, calibration curves
  • Threshold tuning using cost matrix (false negative cost >> false positive)
  • SHAP TreeExplainer: global summary plot + per-prediction waterfall
  • Generate top-5 reason codes per prediction in plain English
Week 5 — Deployment & demo
  • Serialize final model pipeline (joblib/pickle with sklearn Pipeline)
  • FastAPI /predict endpoint with Pydantic input validation
  • Streamlit demo: user inputs → risk score + SHAP waterfall + reason codes
  • Business simulation tab: adjust threshold, see P&L impact
Week 6 — Polish & documentation
  • MLflow experiment tracking: log all runs, params, metrics
  • Evidently AI report for data drift (compare train vs test distribution)
  • Write GitHub README with all sections (see README tab)
  • Record a 2-min Loom demo video, link in README
